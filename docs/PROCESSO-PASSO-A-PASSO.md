# AURORA OMNI KERNEL · fluxo passo a passo

Ponte demonstrativa FastAPI com componentes Python e Rust.

## 1. INICIAR SERVIÇO

Subir a API FastAPI conforme as instruções do projeto.

## 2. RECEBER REQUISIÇÃO

Enviar os dados de demonstração para a rota configurada.

## 3. VALIDAR IDENTIDADE

Executar a verificação simulada de Aurora ID.

## 4. ACIONAR COMPONENTE

Encaminhar a operação ao módulo Python ou Rust disponível.

## 5. RETORNAR RESULTADO

Exibir resposta e registrar limites da simulação.

## Resultado e limites

Protótipo de integração. A validação de identidade é simulada, não equivale a identidade digital real.
